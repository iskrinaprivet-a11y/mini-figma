Редактор векторной графики, собранный в браузере

Mini Figma — учебный редактор на React и TypeScript: холст с сеткой, фигуры протяжкой мыши и история, отменяющая жесты целиком. Открывается прямо в браузере.

Возможности

Что уже работает

  • Камера без сюрпризов

    Зум колесом от 10% до 400% фиксирует точку под курсором. Пробел с мышью — панорама, сетка ездит вместе с холстом.

  • Фигуры протяжкой

    Прямоугольник (R) и эллипс (O) создаются движением мыши. Escape отменяет жест прямо на ходу.

  • Картинки из буфера

    Ctrl+V вставляет изображение в центр вида, перетаскивание файла из проводника — под курсором, в собственных пропорциях.

  • Выделение и рамка

    Клик по фигуре или слою, Shift+клик — несколько сразу. Рамка с восемью маркерами не меняется при зуме.

  • История помнит жесты

    Ctrl+Z отменяет перетаскивание одним нажатием, а не по кадрам. Ctrl+Shift+Z — возврат. Глубина — 50 шагов.

  • Работает на любой раскладке

    V / R / O работают и на русской раскладке: обработчик смотрит на клавишу, а не на букву.

Ctrl+R — перезагрузка страницы, Ctrl+O — открытие файла: мы их не перехватываем. Ctrl+V перехватываем, только если в буфере картинка — вставка текста работает как обычно.

Как устроено

Пять слоёв и одно равенство

Каждая папка отвечает ровно за свою часть и не знает про соседние: компоненты держат экран, хуки — логику без интерфейса, утилиты — чистую математику и работу с файлами, константы — настройки, типы — общий язык проекта.

  • components один компонент — одна зона экрана
  • hooks логика без интерфейса
  • utils математика и файлы без React
  • constants настройки без магических чисел
  • types общий язык проекта

зависимости идут только в одну сторону: components → hooks → utils → constants → types

Ключевая формула

canvas = (screen − pan) / zoom

Единое равенство, на котором держится всё позиционирование. Забытый делитель на зум — классическая причина «уезжающих» фигур при зуме и сдвиге холста.
